# Book Exchange Platform

**Prepared by:** [@AnooshaMohammadi](https://github.com/AnooshaMohammadi) and [@MayKhaleghi](https://github.com/MayKhaleghi)

## Overview

This Django web application enables users to exchange books directly with each other. Developed for a university database course, it provides a platform where students and book enthusiasts can upload book images and request exchanges from other users.

## Key Features

- **Book Upload**: Add books with images and details for exchange
- **Book Requests**: Browse listings and send requests to other users  
- **User Accounts**: Registration, login, and profile management
- **Admin Interface**: Moderation through Django admin panel

## Tech Stack

- Backend: Django (Python web framework)
- Database: SQLite3 (development)
- Frontend: Django templates + static files
- File Uploads: Image handling for book photos
